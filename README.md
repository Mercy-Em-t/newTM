## Live Deployment (GitHub Pages)

This repository is optimized for immediate, zero-configuration hosting via **GitHub Pages**:

1. Open your repository settings on GitHub: `Settings > Pages`.
2. Under **Build and deployment**:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / `/ (root)`
3. Save. Within 60 seconds, your atelier will be live at:
